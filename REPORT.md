# Итоговый отчёт по проекту «Movie Manager»

## Описание проекта

В рамках работы было разработано консольное приложение для управления коллекцией фильмов.

Приложение позволяет:

* добавлять фильмы;
* просматривать список фильмов;
* редактировать информацию о фильмах;
* удалять фильмы;
* фильтровать фильмы по жанру;
* фильтровать фильмы по году выпуска.

Для хранения данных используется JSON-файл.

---

## Используемые технологии

* Python 3
* JSON
* pytest
* Git
* GitHub

---

## Этапы выполнения проекта

### Этап 1. Инициация и требования

Были сформированы пользовательские истории и определён MVP проекта.

Основной функционал:

* CRUD-операции;
* фильтрация по жанру;
* фильтрация по году;
* сохранение данных в JSON.

Для планирования работы использовались GitHub Issues и Kanban-доска.

---

### Этап 2. Проектирование

Была разработана структура хранения данных:

* title — название фильма;
* year — год выпуска;
* rating — рейтинг;
* genre — жанр.

Схема взаимодействия:

Пользователь → Меню → Бизнес-логика → CSV-файл

---

### Этап 3. Разработка и тестирование

Для тестирования использовался pytest.

Были написаны тесты для:

* добавления фильма;
* удаления фильма;
* изменения фильма;
* фильтрации по жанру;
* фильтрации по году;
* проверки некорректных данных.

Разработка выполнялась по принципам TDD.

---

### Этап 4. Приёмочное тестирование

Был составлен чек-лист приёмочного тестирования.

Проверялись:

* корректность CRUD-операций;
* фильтрация данных;
* обработка ошибок;
* сохранение данных между запусками программы.

Все проверки были успешно пройдены.

---

### Этап 5. Сопровождение

В ходе сопровождения были обработаны обращения пользователей:

* исправление ошибки с пустым названием фильма;
* исправление ошибки с рейтингом больше 10;
* добавление фильтрации по году;
* изменение формата вывода;
* обновление документации.

Все изменения отражены в файле SUPPORT_LOG.md.

## Ответы на вопросы

### Что было самым сложным в тестировании?

Наиболее сложным оказалось тестирование некорректного пользовательского ввода и обработка исключительных ситуаций.

### Как изменилось бы приложение, если бы вы сразу знали обо всех багах?

Большинство проверок были бы реализованы сразу, что уменьшило бы количество исправлений после выпуска первой версии.

### Чему вы научились в процессе поддержки?

Был получен опыт поиска ошибок, написания тестов для их воспроизведения и выпуска исправлений.
